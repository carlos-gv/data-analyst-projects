# Data Analyst Projects

A collection of data analysis and business intelligence projects covering the full workflow: data collection via APIs, cleaning and transformation with Python, and dashboard/reporting delivery in Excel, Tableau, and Power BI.

## Projects

### [Coffee Sales Report (Excel)](coffee-sales-project-excel)
Interactive Excel dashboard for a coffee shop, built with pivot tables and dynamic tables. Tracks sales over time, top-selling countries, and top clients, with filters for roast type, coffee size, and loyalty card status.

**Tools:** Excel

### [London Bike Rides (Tableau)](london-bikes-project-tableau)
Interactive Tableau dashboard analyzing London bike ride data from 2015–2017. Visualizes ride volume over time and its relationship to weather conditions (temperature and wind), with drill-downs by hour and moving-average filters. Data was cleaned and transformed with Python/Pandas before loading into Tableau.

**Tools:** Python, Pandas, Tableau
**Live dashboard:** [View on Tableau Public](https://public.tableau.com/app/profile/carlos.eduardo.gutierrez.villamizar/viz/LondonBikeRides_16995048248720/Dashboard1)

### [Pizza Restaurant Sales Report (Power BI + SQL)](pizza-proyect-PWBI-SQL)
Power BI report for a fictional pizza restaurant, with sales data queried and prepared in MySQL. Includes KPIs (revenue, average order value, pizzas sold, orders) and charts breaking down sales by day, hour, category, and size, plus top/bottom seller rankings.

**Tools:** SQL, MySQL, Power BI

### [US Labor Market Data via FRED API](economic-api-fred)
Python notebook that pulls unemployment rate and labor force participation rate data per U.S. state from the FRED (Federal Reserve Economic Data) API, cleans and joins the series, and visualizes the relationship between unemployment and participation across states over time.

**Tools:** Python, Pandas, Matplotlib, Plotly, FRED API

## Tech Stack Summary

- **Languages/Libraries:** Python, Pandas, Matplotlib, Plotly
- **BI/Reporting Tools:** Excel, Tableau, Power BI
- **Databases:** MySQL, SQL
- **APIs:** FRED (Federal Reserve Economic Data)
